Process

Track Games (Lichess retrieval), Positions (Stockfish evaluation), and Coaching (computer-aided coaching analysis) for each game list. Engine-intensive tasks run separately; training can continue.

Games downloads PGNs from Lichess once when a list is created, then starts Positions automatically. Positions screens and deep-evaluates games with Stockfish. Coaching uses its own targeted Stockfish probes and the retained position evaluations to regenerate motifs, context, and explanations. An unchanged coaching probe is reused when its inputs and engine settings match. Clear coaching cache removes generated coaching for one list and requires a new coaching refresh, without deleting saved Stockfish analysis or games. Pause preserves the checkpoint. Restart Analysis deletes this game list’s existing analysis, positions, metadata and learned progress. Durable feedback history remains available for review; export before a restart if you need the old positions’ complete chess context.
