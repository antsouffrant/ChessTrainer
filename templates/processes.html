Process

Monitor game retrieval, Stockfish evaluation, and metadata refresh for each game list. One database-intensive task runs at a time; training can continue while work proceeds.

Retrieval downloads games once when a new list is created. Successful retrieval automatically starts analysis. Analysis uses the saved game batch and Stockfish. Refresh rebuilds lesson motifs, opening labels, difficulty estimates, and explanations using already stored information. Pause preserves the checkpoint. Restart Analysis deletes this game list’s existing analysis, positions, metadata, learned progress, and associated coaching feedback before reanalyzing its saved PGN. Export feedback first if you want to keep it.
